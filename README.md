# Мой почерк — печатный текст в рукописный

Веб-приложение: пользователь регистрируется, "обучает" сайт своему почерку (пишет
буквы на холсте), а затем вставляет текст или загружает фото страницы — сайт
распознаёт текст и генерирует картинку/PDF, как будто это написано от руки
пользователем.

## Структура проекта

```
handwriting-app/
├── backend/            Flask API + отдача фронтенда
│   ├── app.py          точка входа (flask run / python app.py)
│   ├── auth.py         регистрация / вход / выход
│   ├── samples.py      сохранение образцов букв, прогресс обучения
│   ├── generate.py     генерация из текста и из фото (OCR)
│   ├── render.py       склейка букв в "рукописный" лист (Pillow)
│   ├── ocr.py          обёртка над Google Cloud Vision API
│   ├── models.py       модели БД (User, LetterSample)
│   ├── alphabet.py     список символов для обучения
│   ├── config.py       настройки (ключи, папки, БД)
│   ├── requirements.txt
│   └── .env.example
└── frontend/           статический сайт (HTML/CSS/JS без сборки)
    ├── index.html
    ├── css/style.css
    └── js/{api.js, app.js}
```

## Как это работает

1. **Регистрация/вход** — у каждого пользователя свой набор образцов почерка
   (Flask-Login + пароли хранятся хэшированными).
2. **Обучение почерку** — на странице «Обучение» по очереди показываются буквы
   (заглавные, строчные, цифры, знаки препинания). Пользователь рисует букву
   на холсте мышью/пальцем, сервер сохраняет PNG-образец для этого символа.
3. **Генерация**:
   - Перед генерацией можно выбрать **тип бумаги**: чистый лист, линованный,
     клетка, тетрадный лист (с красной линией полей) или состаренная бумага.
     Буквы для линованных вариантов автоматически ложатся на линии.
   - *Из текста*: сервер разбивает введённый текст на символы и для каждого
     подставляет сохранённый образец буквы пользователя, слегка (случайно)
     поворачивая и сдвигая букву для естественности, и собирает всё в
     PNG-картинку и многостраничный PDF (с учётом выбранной бумаги).
   - *Из фото*: фото сначала отправляется в Google Cloud Vision API (OCR) для
     распознавания текста, распознанный текст можно поправить, а затем он
     проходит тот же путь, что и обычный текст.

## Установка и запуск

```bash
cd handwriting-app/backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env            # затем впишите свои значения в .env
# либо экспортируйте переменные окружения вручную (см. ниже)

python app.py
```

Откройте `http://localhost:5000` — фронтенд отдаётся тем же сервером, отдельно
его запускать не нужно.

### Переменные окружения

| Переменная             | Обязательна | Описание                                             |
|-------------------------|:-----------:|-------------------------------------------------------|
| `SECRET_KEY`             | желательно  | ключ для подписи сессий (задайте случайную строку)     |
| `DATABASE_URL`           | нет         | по умолчанию SQLite-файл `handwriting.db`              |
| `GOOGLE_VISION_API_KEY`  | да, для OCR | ключ Google Cloud Vision API (см. ниже)                |
| `PORT`                   | нет         | порт сервера, по умолчанию 5000                        |

Если не задать `.env`, приложение всё равно запустится и обучение/генерация
из текста будут работать — не будет работать только загрузка фото (OCR),
пока не добавите ключ.

## Настройка OCR (Google Cloud Vision API)

Вы выбрали облачный OCR — он точнее, чем офлайн-распознавание, но требует
платный API-ключ Google (у Google Cloud есть бесплatный пробный период и
небольшой бесплатный лимит запросов в месяц).

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/) и
   создайте проект (или используйте существующий).
2. В разделе **APIs & Services → Library** включите **Cloud Vision API**.
3. В разделе **APIs & Services → Credentials** нажмите **Create Credentials →
   API key**.
4. Скопируйте ключ и вставьте его в `.env` как `GOOGLE_VISION_API_KEY=...`.
5. (Рекомендуется) Ограничьте ключ только Vision API и, если возможно, по
   IP/домену — в настройках ключа в консоли.
6. Включите биллинг для проекта — без привязанной карты у Google запросы к
   платным API работать не будут, даже в рамках бесплатного лимита.

Подробная официальная инструкция:
https://cloud.google.com/vision/docs/setup

## Важные заметки и ограничения

- Это рабочий прототип, а не готовый к промышленной нагрузке сервис:
  для реального запуска в интернет стоит добавить HTTPS, лимиты на частоту
  запросов (rate limiting), более надёжное хранилище файлов (например, S3
  вместо локальной папки `uploads/`), и вынести `SECRET_KEY`/OCR-ключ в
  секрет-менеджер, а не хранить в `.env` на сервере.
- Компоновка "рукописного" текста — это склейка реальных образцов букв
  пользователя (не нейросеть), с небольшим случайным поворотом/сдвигом
  каждой буквы для естественности. Чем больше и разнообразнее образцы —
  тем аккуратнее результат.
- OCR распознаёт печатный и рукописный текст на фото, но качество зависит от
  освещения, чёткости и почерка на самом фото.
- "Отправка" результата пользователю реализована как генерация файла и показ
  кнопок «Скачать PNG» / «Скачать PDF» прямо на сайте (пользователь сам
  сохраняет файл себе). Если нужна отправка на email — это несложно добавить
  отдельным шагом (например, через Flask-Mail или SMTP), спросите отдельно.
